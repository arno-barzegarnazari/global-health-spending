# Global Health Spending, 2000–2023

An exploratory data visualization project in R. It looks at how 195 countries fund health care, how much households pay out of pocket, and what the money is spent on.

**[View the report (PDF)](global_health_spending.pdf)**

## Data

[TidyTuesday 2026-04-21](https://github.com/rfordatascience/tidytuesday/blob/main/data/2026/2026-04-21/readme.md), from the WHO Global Health Expenditure Database.

## Run it

Open `global_health_spending.Rmd` in RStudio and knit it. The data is read directly from GitHub.

Required packages: `dplyr`, `tidyr`, `ggplot2`, `readr`, `scales`, `rmarkdown`, plus a LaTeX distribution (e.g. `tinytex`).
